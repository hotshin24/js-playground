# lessons-v2

새 커리큘럼의 작업 디렉터리다. 정식 주소는 계속 `lessons/`를 읽고, `?curriculum=v2`를 붙인 미리보기 주소만 `lessons-v2/`를 읽는다. 두 과정은 서로 다른 localStorage 키를 사용한다.

## 현재 상태

| 트랙 | 상태 |
|---|---|
| T0 실행과 값 | 6레슨 초안·스키마 검사 완료 |
| T1 자료형과 연산 | 15레슨 초안·스키마 검사 완료 |
| T2 조건·반복·함수·스코프 | 16레슨 초안·스키마 검사 완료 |
| T3 객체·배열·참조 | 18레슨 초안·스키마 검사 완료 |
| T4 브라우저 JavaScript와 비동기 | 1~15번 레슨 초안·스키마 검사 완료 |
| T5~T9 | 미작성 |

## 전환 조건

- T0~T9의 모든 JSON이 새 `index.json`과 일치한다.
- 모든 검사 단계에서 solution 통과·starter 실패를 확인한다.
- 새 용어의 첫 등장과 선행 개념 순서를 전수 감사한다.
- 실제 앱 진입점에서 전체 브라우저 회귀를 통과한다.
- 저장 revision을 올린 뒤 `lessons/`를 한 번에 교체한다.
