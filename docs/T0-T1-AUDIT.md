# T0·T1 교육과정 감사

판정 기준은 `CURRICULUM.md`다. 이 문서는 현재 콘텐츠의 실행 가능성이 아니라 왕초보의 학습 가능성을 기록한다.

## 판정 기호

- **유지** — 목표와 문제 요구가 일치한다.
- **보강** — 순서는 유지하되 정의·실행·바꾸기 중 빠진 고리를 채운다.
- **분리** — 새 개념이 둘 이상이라 레슨이나 단계를 나눈다.
- **축소** — 쓰기 문제가 레슨 목표보다 큰 종합 문제다.

## T0

| 레슨 | 목표 | 판정 | 수정 |
|---|---|---|---|
| T0-01 | 값에 이름 붙이기 | 보강 | `변수`와 `선언`을 실제 용어로 첫 문단에 넣고, `const` 재할당 오류는 관찰까지만 둔다. |
| T0-02 | 출력으로 값 확인 | 유지 | `console.log`가 값을 반환하는 것이 아니라 출력한다는 현재 대비를 유지한다. |
| T0-03 | 함수 호출과 반환 | 보강 | `매개변수`와 함께 `인자`를 명시하고, 쓰기는 함수 골격을 그대로 복원하는 작은 문제로 유지한다. |

T0는 2026-08-22 재작성으로 큰 도약이 대부분 해소됐다. T1 이후에서 T0 용어를 다른 말로 바꾸지 않는 것이 남은 일이다.

## T1

| 레슨 | 현재 새 개념 | 판정 | 확인된 문제 | 수정 방향 |
|---|---|---|---|---|
| T1-01 | 타입·`typeof`·비교 | 분리 | 제목과 실행은 타입인데 검사와 쓰기는 비교 함수다. 비교 연산자를 실행·변경하지 않고 바로 채운다. | 타입 관찰과 비교/불리언 생성을 별도 학습 단위로 나눈다. |
| T1-02 | `if`·`else if`·삼항 | 분리 | 분기문과 값 하나를 고르는 식을 한 read에서 동시에 정의한다. 쓰기는 `if`, 이후 레슨은 삼항도 이미 배웠다고 가정한다. | 본 과정은 `if/else`에 집중하고 삼항은 독립 실행·채우기 뒤에만 사용한다. |
| T1-03 | 객체·프로퍼티·새 객체 구성 | 보강 | 객체를 만드는 것과 필요한 필드만 골라 새 객체를 만드는 일을 한 번에 다룬다. | 첫 절반은 생성·접근, 뒤 절반은 이미 본 프로퍼티로 새 객체 만들기로 경계를 표시한다. |
| T1-04 | 형변환·NaN 판별 | 축소 | 쓰기에서 `typeof`, `String`, `Number`, `Number.isNaN`, 삼항, 객체 조립을 동시에 요구한다. “직접 찾아야 합니다”는 왕초보 계약과 어긋난다. | `Number.isNaN` 한 가지를 복원하는 문제로 축소하고 종합은 T1 후반으로 옮긴다. |
| T1-05 | 배열·인덱스·`length`·`join`·`push` | 분리 | `join`과 `push`가 read에서 정의되지 않은 채 run에 처음 나오며, fill은 즉시 `join`을 요구한다. | 기본 레슨은 배열·인덱스·length로 제한한다. `join`은 별도 완성형과 변경을 거친다. `push`는 이후 변경 레슨으로 옮긴다. |
| T1-06 | `for...of`·`let`·재할당·누산 | 분리 | T0에서 미룬 `let`이 run 설명에서 처음 나오며 곧바로 합계·개수 누산을 요구한다. | `let`과 재할당을 read의 작은 실행으로 먼저 배우고, 그 다음 순회에서 사용한다. |
| T1-07 | 함수를 값으로 전달·콜백 | 보강 | 콜백의 “누가 언제 어떤 인자로 호출하는가” 계약이 약하면 뒤 배열 메서드가 암기가 된다. | 직접 만든 `applyTwice` 같은 가장 작은 호출자를 실행해 콜백 계약을 눈으로 보인다. |
| T1-08 | 화살표 함수 | 보강 | 축약형을 여러 형태로 한꺼번에 줄이면 괄호·중괄호·암시적 반환이 섞인다. | 매개변수 괄호, 본문 중괄호, 암시적 반환을 한 번에 하나씩 제거한다. |
| T1-09 | 클로저 | 보강 | 결과는 보이지만 “함수마다 바깥 변수가 따로 살아 있다”는 시간·소유 관계가 추상적이다. | 생성 시점과 호출 시점을 출력하고 카운터 두 개의 독립된 `count`를 표로 복원한다. |
| T1-10 | `map` | 보강 | 콜백이 받는 값과 반환값이 새 배열의 값이 된다는 계약을 고정해야 한다. | 입력 값 → 콜백 반환 → 결과 배열을 같은 위치끼리 대응해 보여 준다. |
| T1-11 | `filter` | 보강 | 새 배열 메서드인데 `read → fill → wrap → write`라 완성형 실행과 실패 관찰이 없다. | run과 tweak를 추가한다. 콜백이 값 자체가 아니라 포함 여부 불리언을 반환한다는 점을 비교한다. |
| T1-12 | `reduce` | 보강 | 누산값, 현재값, 시작값 세 요소가 동시에 등장한다. “접다” 흔적은 고쳤지만 정신 모델이 여전히 압축돼 있다. | 반복 회차별 `acc`, `item`, 반환값을 표와 로그로 보여 주고 합계 하나만 먼저 다룬다. |
| T1-13 | 구조 분해·기본값·단축 속성명 | 분리 | 서로 다른 문법 세 개를 한 read에서 정의하고 write에서 모두 요구한다. | 구조 분해를 먼저 완결한 뒤 기본값을 추가한다. 단축 속성명은 새 객체 만들기 복습으로 분리한다. |
| T1-14 | 객체 전개·덮어쓰기 순서 | 보강 | 제목은 필요한 것만 고르기지만 실제 핵심은 객체 펼치기와 병합이다. | 제목을 실제 목표에 맞추고, 펼치기와 덮어쓰기 순서를 각각 실행한다. |
| T1-15 | 템플릿 리터럴 | 축소 | 쓰기에서 `map`, 삼항, 템플릿 리터럴, `join`, HTML 조립을 동시에 요구한다. | 본 레슨 쓰기는 항목 한 줄 또는 단순 목록까지만 둔다. 전체 목록 조립은 T1 종합으로 이동한다. |
| T1-16 | IIFE·스코프·클로저·모듈 패턴 | 분리 | 즉시실행함수 문법과 정보 은닉 설계를 동시에 가르치며 쓰기는 중첩 함수·배열·반복·요약까지 요구한다. | IIFE 실행과 스코프 관찰을 먼저 끝내고, 공개 함수 객체를 만드는 모듈 패턴은 별도 선택 심화로 둔다. |
| T1-17 | 타이머·비동기 순서·Promise 생성 | 분리 | setTimeout의 순서와 Promise 생성/resolve를 한 레슨에서 배우고 쓰기에서 반복 합계까지 조립한다. | 비동기 순서 관찰과 Promise 생성 학습을 분리한다. 합계는 미리 제공하고 `resolve` 시점과 값에 집중한다. |

## 즉시 수정 우선순위

1. **P0 — 문제에서 처음 가르치는 곳:** T1-01, T1-05, T1-06, T1-11, T1-13
2. **P1 — 한 레슨 과부하:** T1-02, T1-04, T1-15, T1-16, T1-17
3. **P2 — 정신 모델 보강:** T1-07~10, T1-12, T1-14

## 구조 변경 원칙

기존 레슨 ID를 한꺼번에 밀면 저장된 학습 코드와 문서 참조가 모두 어긋난다. 첫 개편에서는 ID를 유지하면서 단계를 늘리거나 목표를 축소한다. 정말 독립 레슨이 필요하면 T1 전체 개편안이 확정된 뒤 한 번만 재번호를 매기고, 저장 `revision`을 올려 오래된 진행 데이터를 명시적으로 무효화한다.
