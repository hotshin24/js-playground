# CURRICULUM MIGRATION — 기존 113레슨 판정

`CURRICULUM.md`의 새 과정으로 전환하기 위한 기존 콘텐츠 분류다. 기존 레슨 ID와 새 레슨 ID는 의미가 다르므로 파일을 그대로 이동하지 않는다.

## 판정

| 기호 | 뜻 | 처리 |
|---|---|---|
| **A** | 예제·scaffold·assert를 재사용할 가치가 있음 | 새 설명과 단계 순서 안에 필요한 코드만 옮긴다. |
| **B** | 소재나 한 장면만 재사용 가능 | 원문과 문제는 폐기하고 아이디어만 새로 작성한다. |
| **X** | 새 필수 과정에서 제외 | 새 인덱스에 넣지 않는다. 필요하면 후속 심화 후보로 보관한다. |

- 식별자와 명명 규칙

- Symbol·BigInt
- 암시적 형변환

- 논리 연산자, truthy/falsy, 단락 평가, `??`
- `switch`, 전통적인 `for`, `break`, `continue`
- 함수 선언·표현식과 호이스팅의 대조
- 전역·함수·블록 스코프와 TDZ
- 원시값 복사와 객체 참조
- 얕은 복사와 중첩 객체

- 배열 추가·삭제·탐색 메서드

## 구현 순서

1. 새 파일은 `lessons-v2/`에서 작성한다.
2. T0 한 트랙을 완성하고 독립 검증한다.
3. A 판정 레슨에서도 지문은 복사하지 않고 새 계약에 맞춰 작성한다.
4. scaffold와 assert를 옮길 때 현재 러너 제약에 종속된 보조 코드를 다시 검사한다.
5. T0~T9가 모두 통과한 뒤 `lessons/`와 인덱스를 한 번에 교체한다.

이 문서의 판정은 “현재 레슨이 나쁘다”는 평가가 아니라 새 의존 순서에서 어떤 자산을 재사용할 수 있는지에 대한 이주 판단이다.
