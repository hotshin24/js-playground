# CURRICULUM — 왕초보 학습 계약

이 문서는 레슨이 실행되는지만이 아니라, **앞에서 배운 것만으로 다음 문제를 풀 수 있는지**를 판단하는 기준이다.
앱의 기능 요구사항은 `PRD.md`, 실행 계약은 `SPEC.md`, 측정 기록은 `FINDINGS.md`가 맡고 이 문서는 교육과정만 맡는다.

## 1. 학습자 전제

- HTML과 CSS는 읽고 작성할 수 있다.
- 자바스크립트의 변수·함수·배열·객체를 모른다고 가정한다.
- 영어 오류 메시지와 개발 용어를 처음 본다고 가정한다.
- 앞 레슨을 통과했더라도 개념 이름과 코드를 바로 떠올리지는 못한다고 가정한다.
- 이 플레이그라운드 밖의 강의나 문서를 먼저 보지 않아도 진행할 수 있어야 한다.

## 2. 레슨 하나의 계약

레슨 하나는 핵심 개념 하나만 새로 가르친다. 새 개념은 다음 순서를 거친 뒤에만 문제에서 요구할 수 있다.

1. **이름 붙이기** — 실제 개발 용어와 필요한 이유를 설명한다.
2. **완성형 보기** — 가장 작은 완성 코드를 보여 준다.
3. **실행하기** — 결과에서 무엇을 볼지 먼저 말하고 실행한다.
4. **바꿔 보기** — 한 부분만 바꿔 원인과 결과를 비교한다.
5. **채우기** — 방금 본 코드에서 한 자리만 복원한다.
6. **옮겨 쓰기** — 같은 개념을 작은 새 문제에 적용한다.

`write`에서 새 문법이나 새 API를 처음 꺼내지 않는다. 종합 레슨은 새 개념을 가르치지 않는다.

## 3. 배웠다고 인정하는 조건

코드나 지문에 등장한 것만으로는 배운 것으로 보지 않는다. 아래 네 조건을 모두 만족해야 뒤 레슨의 선행 개념으로 쓸 수 있다.

- 실제 용어가 정의됐다.
- 최소 한 번 완성 코드를 실행했다.
- 학습자가 한 부분을 직접 바꿔 결과 차이를 확인했다.
- 검사 단계에서 그 개념 하나를 직접 사용했다.

단순히 읽기 전용 보조 코드에 들어 있는 문법은 선행 학습으로 계산하지 않는다.

## 4. 단계별 허용 범위

| 단계 | 새 개념 | 학습자에게 요구할 수 있는 일 |
|---|---:|---|
| 읽기 | 1개 | 이름·필요·작동 원리 이해 |
| 실행 | 0개 | 완성형의 입력과 결과 연결 |
| 바꾸기 | 0개 | 지시된 한 부분 변경과 결과 관찰 |
| 채우기 | 0개 | 직전 완성형의 한 자리를 복원 |
| 감싸기 | 0개 | 이미 쓴 식을 함수로 옮기기 |
| 쓰기 | 0개 | 앞에서 연습한 모양을 작은 새 문제에 적용 |

보조 코드가 길어야 한다면 학습자가 고칠 영역과 경계를 분명히 표시한다. 보조 코드의 내부 동작을 알아야 답을 쓸 수 있으면 레슨을 나눈다.

## 5. 용어 규칙

쉬운 설명은 실제 용어를 없애지 않고 옆에서 뜻을 푼다.

> 반환(return — 함수가 만든 값을 호출한 자리로 보내는 것)

첫 정의 뒤에는 같은 개념을 같은 말로 부른다. 한국어 개발 문서와 강의에서 검색할 수 없는 대체어를 만들지 않는다.

| 실제 용어 | 첫 등장 | 첫 설명 뒤에 쓸 말 |
|---|---|---|
| 값 | T0-01 | 값 |
| 변수 | T0-01 | 변수 또는 값에 붙인 이름 |
| 선언 | T0-01 | 선언 |
| 출력 | T0-01 | 출력 |
| 함수·호출·매개변수·인자·반환 | T0-03 | 각 실제 용어 |
| 타입 | T1-01 | 타입 |
| 불리언 | T1-01 | 불리언 또는 참·거짓 값 |
| 조건식·분기 | T1-02 | 조건식·분기 |
| 객체·프로퍼티·접근 | T1-03 | 각 실제 용어 |
| 배열·인덱스 | T1-05 | 각 실제 용어 |
| 반복·순회 | T1-06 | 반복·순회 |
| 콜백 | T1-07 | 콜백 |
| 클로저 | T1-09 | 클로저 |
| 렌더링 | T3-01 | 렌더링 |
| 컴포넌트·props | T3-05~06 | 각 실제 용어 |
| 상태·렌더 | T4-01 | 각 실제 용어 |
| 효과·정리 함수 | T4-13~14 | 각 실제 용어 |
| Promise·이행·거부 | T1-17·T5-04 | 쉬운 설명을 병기한 실제 용어 |

제목에는 찾기 쉬운 표현을 쓸 수 있지만, 본문에서는 첫 문단 안에 실제 용어를 밝혀야 한다.

## 6. 선행 개념을 다시 부르는 법

`앞에서 배웠습니다`만 쓰지 않는다. 개념과 당시 코드 모양을 한 문장으로 복원한다.

나쁜 예:

> T1에서 배운 클로저입니다.

좋은 예:

> T1-09에서 안쪽 함수가 바깥의 `count`를 기억하는 것을 클로저라고 배웠습니다. 이번에는 효과마다 만든 `ignore`를 정리 함수가 기억합니다.

레슨 번호는 보조 정보다. 번호만으로 기억을 요구하지 않는다.

## 7. 레슨 감사표

각 레슨을 고치기 전에 아래 항목을 기록한다.

| 항목 | 질문 |
|---|---|
| 목표 | 끝난 뒤 학습자가 할 수 있는 한 가지는 무엇인가 |
| 선행 개념 | 앞 레슨에서 네 조건을 충족한 것만 적었는가 |
| 새 개념 | 하나뿐인가 |
| 첫 정의 | 실제 용어와 쉬운 설명이 함께 있는가 |
| 완성형 | 문제 전에 같은 코드 모양을 실행했는가 |
| 바꾸기 | 원인 하나와 결과 하나만 비교하는가 |
| 채우기 | 새 지식 없이 직전 모양을 복원할 수 있는가 |
| 쓰기 | 백지 범위가 작고 평가 목표가 하나인가 |
| 보조 코드 | 몰라도 되는 코드가 답을 방해하지 않는가 |
| 힌트 | 새로 가르치지 않고 돌아볼 위치를 가리키는가 |

## 8. 트랙 경계

- **T0** — 값, 변수, 출력, 함수, 호출, 매개변수, 인자, 반환과 도구 사용
- **T1** — 자바스크립트 값과 흐름, 배열·객체·함수의 기본 조작
- **T2** — DOM 조회·변경, 이벤트, 폼, 접근성
- **T3** — JSX, 컴포넌트, props, 목록·조건부 렌더링
- **T4** — 상태, 렌더, 불변 갱신, 효과, Context, 커스텀 훅
- **T5** — 동기 에러, Promise, async/await, fetch, 병렬 처리
- **T6** — T3~T5를 조립한 작은 React 앱
- **T7** — `this`, 프로토타입, class를 읽기 위한 선택 심화
- **T8** — 기본 모듈과 컴포넌트 파일 분리. 평가 순서·순환은 선택 심화

뒤 트랙의 개념을 맛보기로 보여 줄 수는 있지만, 학습자에게 수정하거나 작성하게 해서는 안 된다.

## 9. 완료 기준

트랙 개편은 다음을 모두 만족해야 끝난다.

- 감사표에서 선행 개념 누락이 0건이다.
- 새 용어는 첫 등장에 정의된다.
- `fill`·`wrap`·`write`에서 처음 등장하는 문법이 0건이다.
- solution은 전부 통과하고 starter는 전부 실패한다.
- 학습자가 읽지 않아도 되는 보조 코드가 문제 영역과 분리돼 있다.
- 실제 초보자 관점의 수동 학습 기록을 남긴다. 자동 검사는 이를 대신하지 않는다.
