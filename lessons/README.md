## 전수 검사

```sh
node scripts/audit-lessons.mjs
```

앱이 실제로 사용하는 `validateLesson`으로 199개 파일을 읽고, 인덱스 일치 여부·트랙별 순서·runtime·단계 구성·직접 작성 단계의 정답과 검사 항목을 확인한다.
